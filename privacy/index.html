Privacy Policy

Last updated 13 October 2026

PyPrompt has no analytics, tracking, advertising, or crash reporting. There is no account to create. The only data that leaves your device is data you explicitly choose to send: a notebook you share, a model your script saves, a prompt your code gives an agent, or a network request your code makes.

Where your data lives

On your device. Python scripts execute entirely on your device. Your source code, session history, and results remain on your device or in your private iCloud storage unless code you choose to run sends information through a network request or connection.

In your private iCloud storage. Your notebooks, history, and app data sync between your own devices through your private iCloud database. The developer has no access to it and cannot read what it contains.

In the app's public iCloud database. The icloud module saves data models to a public database in the app's iCloud container. Saving a model returns a record ID, and anyone with that ID can fetch the record, so this data is public. Saving requires your own iCloud account; fetching does not. Only the account that saved a record can change or delete it. Nothing is written there unless a script you run explicitly saves it. The developer does not read, monitor, or use this data.

Shared notebooks. When you share a notebook as a link, its content is saved to that same public database. The link carries the record ID, so anyone holding the link can open the notebook, and no iCloud account is needed to do so. The notebook stays there until you remove it: changes you make afterwards reach everyone holding the link, and removing it makes the link stop working. A link is unlisted and is distributed only by you. There is no way for anyone to browse or discover shared notebooks.

In your keychain. Secrets you store with the keychain module, such as an API key, are kept in the system keychain and sync through iCloud Keychain, or stay on the device when iCloud Keychain is unavailable. Scripts use a secret without its value being exposed to Python code. The developer has no access to it.

With Apple Intelligence. Code that uses the agents module, including built-in examples such as Game master, sends its prompts and context to Apple's language models. By default they run on Apple's Private Cloud Compute when it is available, and on the model on your device otherwise; code can instead require the on-device model, in which case prompts never leave the device. Private Cloud Compute is operated by Apple, not the developer, and the developer does not receive these prompts or the model's responses.

Between your devices, directly. PyPrompt can connect to other devices running PyPrompt on the same local network, which is why iOS asks for local network permission. That data travels straight from one device to the other and never passes through any server operated by the developer.

Two things worth knowing

Local network connections are not encrypted. Data sent between peers on your local network travels in the clear, and a device on the same network can connect to a session you are hosting. Use this feature on networks you trust.

Scripts you run can communicate with external services. Python code can make HTTP or HTTPS requests and open other supported connections. Any information included in a request is sent directly from your device to the destination specified by the code. The developer of PyPrompt does not receive, store, or process these requests or their responses.

Built-in examples do not make network requests until you choose to run them. Any external service contacted by a script or example may receive standard network information, such as your IP address and request headers, and may process that information according to its own privacy practices.

Third parties

PyPrompt does not send information to analytics providers, advertising services, or tracking services. iCloud, iCloud Keychain, and Apple Intelligence, including Private Cloud Compute, are provided by Apple and governed by Apple's Privacy Policy.

When code you run connects to an external service, that service receives the information included in the request. Its own terms and privacy policy apply. PyPrompt does not control, inspect, or retain that communication.

Changes

If this policy changes, the updated version will be posted on this page with a new date. Significant changes will be noted in the app's release notes.
