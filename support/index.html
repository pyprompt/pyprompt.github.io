Reporting a problem

Including these details helps a lot:

  • Your device and iOS version (e.g. iPhone 16, iOS 26.1)
  • The PyPrompt version, shown at the top of the console
  • What you did, what you expected, and what happened instead
  • The script or console output involved, if you can share it

Common questions

Do I need an internet connection?
Not for PyPrompt itself — Python runs on your device. A connection is only needed when something reaches beyond it, such as a script that makes a request, sharing a session, or saving a model with the icloud module.

Who can see a session I share?
Anyone with the link. A shared session is stored in a public iCloud database and the link carries its record ID, so no iCloud account is needed to open one. Links are unlisted and only you hand them out, but treat a shared session as public. Removing the session makes its link stop working.

How do I run a script from Shortcuts?
Add the Run Script action from PyPrompt to any shortcut and pass it the Python source to execute. It returns the script's output.
