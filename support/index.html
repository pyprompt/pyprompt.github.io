Reporting a problem

Including these details helps a lot:

  • Your device and system version (for example iPhone 16 on iOS 27.1, or a MacBook Air on macOS 27)
  • The PyPrompt version
  • What you did, what you expected, and what happened instead
  • The script or console output involved, if you can share it

Common questions

Do I need an internet connection?
Not for PyPrompt itself — Python runs on your device. A connection is only needed when something reaches beyond it, such as a script that makes a request, an agent running on Apple's Private Cloud Compute or on Claude, sharing a notebook, or saving a model with the icloud module.

How do I use Claude models?
Pass one from the claude module to an agent, for example Agent(model=claude.sonnet()). You need your own Anthropic API key: PyPrompt asks for it the first time and keeps it in your keychain, where scripts can use it without reading its value. Usage is billed to your Anthropic account.

Who can see a notebook I share?
Anyone with the link. A shared notebook is stored in a public iCloud database and the link carries its record ID, so no iCloud account is needed to open one. Links are unlisted and only you hand them out, but treat a shared notebook as public. Removing the notebook makes its link stop working.

Can someone open my shared notebook without the app?
On an iPhone or iPad, yes. Opening the link in Safari offers an App Clip, a small part of PyPrompt that opens the notebook with no download from the App Store. On a Mac or Apple Vision Pro they need the app.

How do I run a script from Shortcuts?
Add the Run Script action from PyPrompt to any shortcut and pass it the Python source to execute. It returns the script's output.
