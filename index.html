PyPrompt

Learn Python by writing it.

PyPrompt brings Python 3.15 to iPhone, iPad, Mac and Apple Vision Pro, with courses that check your code, exercises to practice, and a notebook for your own ideas. Python is built in, so there is nothing to install or configure.

Learn step by step

Python Basics takes you from your first line of code to a task tracker in 74 short lessons. Checks tell you the moment your code works, and your progress is saved.

Practice by difficulty

Over a hundred exercises, from easy to hard, each with a function ready for your solution and checks that tell you when it's right.

An assistant in your notebook

Ask it to explain an error, draft a function or tidy up your code. You review every change, and nothing runs until you allow it. Use Apple Intelligence, or your own Claude or OpenAI API key.

Hints as you type

Pyright checks your code while you write: likely mistakes are underlined before you run, and suggestions help you finish names.

Make something useful

Fetch data from the web, draw with Apple Pencil, play sounds, build small apps with buttons, sliders and forms, or run Python from Shortcuts.

Pick up where you left off

iCloud keeps your notebooks and progress on all your devices, and a notebook's timeline lets you restore an earlier version.
